# 🏋️ Gym Landing Page

A modern, responsive, and visually engaging Gym Landing Page built using **HTML**, **CSS**, and **JavaScript**. The website is designed to promote a fitness center with an attractive layout, smooth navigation, and a professional user interface.

## 🌐 Live Demo

👉 https://rishyandhark-sudo.github.io/web-dev-projects/proj4-GYM/

## 📂 GitHub Repository

👉 https://github.com/rishyandhark-sudo/web-dev-projects/tree/main/proj4-GYM

---

## ✨ Features

- 🏋️ Modern and responsive design
- 📱 Mobile-friendly layout
- 🧭 Smooth navigation
- 🎯 Hero section with call-to-action
- 💪 Programs/Services section
- 👨‍🏫 Trainer showcase
- ⭐ Testimonials section
- 📞 Contact section
- ⚡ Interactive elements using JavaScript
- 🎨 Clean and attractive UI

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/rishyandhark-sudo/web-dev-projects.git
```

2. Navigate to the project folder

```bash
cd web-dev-projects/proj4-GYM
```

3. Open `index.html` in your browser

Or use the **Live Server** extension in VS Code.

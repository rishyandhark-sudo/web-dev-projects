# 📸 Photography Portfolio Website

A modern, premium photography portfolio website built using **only HTML5 and CSS3**. The design embraces a dark, minimal, cinematic aesthetic with smooth CSS animations, responsive layouts, and elegant micro-interactions—without using JavaScript or any CSS frameworks.

> Designed as a single-file project (`index.html`) with all styles inside an internal `<style>` tag.

## ✨ Features

- 🎨 Modern dark premium UI
- 📱 Fully responsive design
- ⚡ Built using only HTML5 & CSS3
- 🚫 No JavaScript
- 🚫 No Bootstrap or Tailwind CSS
- 🎞️ Hero section with smooth CSS entrance animations
- 🖼️ Responsive CSS Grid gallery
- 🔍 Image zoom and overlay hover effects
- 📝 Animated navigation underline effects
- 👤 Elegant About section
- 📬 Stylish Contact form with animated focus states
- 🌊 Native smooth scrolling
- 🎯 Pure CSS micro-interactions throughout

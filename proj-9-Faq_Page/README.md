# 📚 FAQ Page

A simple and responsive **Frequently Asked Questions (FAQ) Page** built using **HTML and CSS**.

This project is designed to practice webpage structure, styling, spacing, typography, and responsive design while creating a clean FAQ interface.

## 🚀 Live Demo

[View Live Demo](https://rishyandhark-sudo.github.io/web-dev-projects/proj-9-Faq_Page/)

## 🛠️ Technologies Used

* HTML5
* CSS3

## ✨ Features

* Clean and simple FAQ layout
* Responsive design
* Easy-to-read typography
* Styled FAQ questions and answers
* Organized sections for better readability
* Beginner-friendly HTML and CSS implementation

# 🎓 SAHE Student Club Website

A modern, responsive, and minimal student club website designed for **Siddhartha Academy of Higher Education (SAHE)**. Built using only **HTML5, CSS3, and JavaScript**, this project showcases a clean user interface with smooth interactions, making it suitable for college clubs, student organizations, and academic communities.

---

## ✨ Features

- 📱 Fully Responsive Design
- 🎨 Modern & Minimal User Interface
- 🧭 Sticky Navigation Bar
- 🚀 Hero Section with Call-to-Action Buttons
- 📖 About Club Section
- 📊 Club Highlights & Statistics
- 📅 Upcoming Events Cards
- 👥 Core Team Showcase
- 🔗 Social Media & Contact Footer
- ✨ Smooth Hover Animations
- ⚡ Fast, Lightweight & Easy to Customize

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6)

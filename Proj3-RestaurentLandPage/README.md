# 🍽️ Restaurant Landing Page

A modern and responsive Restaurant Landing Page built using **HTML**, **CSS**, and **JavaScript**. This project showcases a visually appealing user interface with smooth navigation and a clean layout, making it suitable for restaurants, cafés, and food businesses.

👉 https://rishyandhark-sudo.github.io/web-dev-projects/Proj3-RestaurentLandPage/

## ▶️ How to Run Locally

1. Clone the repository

```bash

```

2. Open the project folder

```bash
cd web-dev-projects/Proj3-RestaurentLandPage
```

3. Open `index.html` in your browser

or use **Live Server** in VS Code.
